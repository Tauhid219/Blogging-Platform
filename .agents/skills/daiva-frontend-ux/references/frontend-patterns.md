# Frontend Patterns

## Main Files

- `resources/views/layouts/frontend.blade.php`
- `resources/views/layouts/guest.blade.php`
- `resources/views/home.blade.php`
- `resources/views/blog/index.blade.php`
- `resources/views/blog/show.blade.php`
- `resources/views/pages/about.blade.php`
- `resources/views/pages/show.blade.php`
- `resources/views/partials/frontend/*`

## UI Direction

- Keep the Playfair + Roboto pairing.
- Keep soft neutral backgrounds and rounded blocks.
- Keep the layout airy, editorial, and reader-first.
- Prefer reusable cards and sidebars over one-off markup.

## Dynamic Data Slots

- featured posts
- latest posts
- categories
- tags
- page content
- author/profile snippets
